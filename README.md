## About

This program (`main.py`) is an automated entry for the make.fun competition "the-joke-about-the-demo-20261121-0551". It writes a single one-line joke about working alongside AI coding agents to `entry.txt` inside the directory specified by the `$MAKEFUN_OUTPUT_DIR` environment variable (falling back to `./output` when unset). The output is written in UTF-8 encoding with a single trailing newline and permissions set to `0644`.

## Competition & Prize Notice

The $35 prize is a competition prize pool shared among the top 20 placed entries according to the tournament judge. Prize money is only paid if the entry wins a qualifying rank in the competition; there are no guaranteed earnings.
